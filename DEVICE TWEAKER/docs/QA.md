# Локальный QA

Скрипты, тесты и тест-панель находятся в [dev/qa](../../dev/qa/README.md).

Из корня репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\dev\qa\Invoke-Qa.ps1
```

Проверки выполняются на отдельном невидимом рабочем столе, без применения настроек Windows и загрузки драйвера. Исходники копируются в папку прогона; сборка и тесты работают с этой копией. Результаты и SHA-256 входных файлов сохраняются в `DEVICE TWEAKER/tmp/qa/`. Видимая отладка запускается только явно через `-VisibleGui`.

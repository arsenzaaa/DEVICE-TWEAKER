# DEVICE TWEAKER

**DEVICE TWEAKER** — утилита для Windows 10 и Windows 11, объединяющая MSI Utility, Interrupt Affinity Policy Tool, ReservedCpuSets, RSS, NIC ITR и управление IMOD в одном, более удобном интерфейсе с интеллектуальной авто-оптимизацией.

Текущая версия: [v0.0.4-alpha.2](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.4-alpha.2).

Исходный код находится в папке [`DEVICE TWEAKER`](./DEVICE%20TWEAKER).

# DEVICE TWEAKER v0.0.1

Первый публичный выпуск приложения для Windows 10/11 x64.

- Интерфейс Windows Forms с тёмной темой и фильтрацией устройств.
- Настройка `MSISupported` для запроса MSI/MSI-X. Фактический режим доставки прерываний зависит от устройства и драйвера.
- Запись `DevicePolicy` и `AssignmentSetOverride` для выбора допустимых логических процессоров прерываний устройства.

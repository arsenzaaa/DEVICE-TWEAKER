# Релиз DEVICE TWEAKER v0.0.1

## Что нового в этой версии

- **Первый публичный релиз:** начальная версия программы DEVICE TWEAKER для 64-битных систем Windows 10 и Windows 11.
- **Управление режимами прерываний (MSI / MSI-X):** переключение контроллеров шины PCI Express в векторный режим через параметр `MSISupported`.
- **Маршрутизация прерываний (CPU Affinity):** конфигурация параметров `DevicePolicy` и масок `AssignmentSetOverride` в системном реестре для привязки устройств к выбранным логическим процессорам.
- **Графический интерфейс:** темная тема оформления на платформе Windows Forms с базовой фильтрацией устройств.

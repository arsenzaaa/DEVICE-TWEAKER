Первый публичный выпуск приложения для Windows 10/11 x64.

- Интерфейс Windows Forms с тёмной темой и фильтрацией устройств.
- Настройка `MSISupported`, `MessageNumberLimit` и `DevicePriority`. Фактический режим доставки прерываний зависит от устройства и драйвера.
- Запись `DevicePolicy` и `AssignmentSetOverride` для выбора допустимых логических процессоров прерываний устройства; настройка `ReservedCpuSets`.
- Настройка базового CPU для RSS сетевого адаптера.
- Настройка xHCI IMOD через WinIO с сохранением конфигурации для повторного применения.

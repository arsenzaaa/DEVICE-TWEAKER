# Релиз DEVICE TWEAKER v0.0.4-alpha.2

## Что нового в этой версии

- **Разделение REFRESH и CHECK:** сканирование списка устройств (кнопка `REFRESH`) отделено от аппаратного опроса контроллеров (кнопка `CHECK`). Обычное обновление работает исключительно через SetupAPI и системный реестр без обращения к Ring 0 драйверу.
- **Быстрое определение CPPC2:** получение аппаратных рейтингов ядер переведено на прямое чтение событий ядра Windows ETW (`Microsoft-Windows-Kernel-Processor-Power`, Event ID 55, поле `MaximumPerformancePercent`). Время опроса сократилось с 2500 мс до менее 60 мс.
- **Поддержка сетевых карт:** добавлены профили для Intel Ethernet I225-K (`15F7`) и I225-I (`15F8`) в дополнение к линейкам I210/I211, I225-V/LM, I226 и I350.
- **Смена языка на лету:** переключатель EN / RU прямо в интерфейсе без необходимости перезапускать программу (`UiLanguage`).
- **Информативные окна результатов:** подробный отчет по каждому параметру (MSI, Affinity, RSS, IMOD, ReservedCpuSets) с кнопками быстрого перехода к логам и бэкапам.
- **Безопасность и бэкапы:** обязательный авто-снимок перед любыми изменениями, защита заводского снимка системы (`DeviceTweakerBackup_ORIGINAL.json`) от перезаписи и возможность быстрого отката.
- **Логика авто-оптимизации:** видеокарта фиксируется на паре соседних физических P-ядер с обязательным пропуском Core 0, мышь и сетевая карта разводятся по разным ядрам во избежание пересечения DPC.
- **Модульные тесты:** добавлен тестовый набор xUnit (41 тест) для автоматической проверки парсинга ядер, CPPC, битовых масок и системного параметра ReservedCpuSets.

# Релиз DEVICE TWEAKER v0.0.3

## Что нового в этой версии

- **Настройка очередей NDIS RSS:** управление параметрами сетевых адаптеров `*NumRssQueues` (ограничение очередей) и `*RssBaseProcNumber` (смещение базового ядра обработки с CPU 0).
- **Приоритеты авто-оптимизации:** скорректирован порядок привязки очередей для сетевых устройств.
- **Фильтрация устройств:** улучшено разделение устройств по категориям (USB/HID, Display, Audio, Storage).
- **Диагностика:** расширено логирование операций с устройствами и кодов ошибок SetupAPI в журнал сессии.

# DEVICE TWEAKER v0.0.3

[История изменений](../../../CHANGELOG.md) · [Скачать релиз](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.3)

## Что изменилось после v0.0.2

- Добавлено управление числом RSS-очередей и вывод активного состояния адаптера отдельно от записанных параметров.
- Переработана автооптимизация с учётом физических ядер, P/E-cores, SMT/HT, CPPC и AMD CCD/CCX. GPU получает два физических ядра; ненадёжно определённые назначения пропускаются с причиной в отчёте.
- Разделены записанный MSI Mode, оценка по выделенным IRQ и аппаратные возможности. Для MSI Limit добавлено отображение Unlimited и проверка числового значения. Пустая маска Interrupt Affinity возвращает политику Windows.
- Исправлено соответствие `AllClose` и `All` значениям `DevicePolicy`: `1` и `3` соответственно. В 0.0.2 эти политики читались и записывались с перепутанными подписями.
- Управление xHCI IMOD переведено с WinIO на `DTIMOD.sys` и KDU: к настройке контроллера добавлены отдельные значения для interrupter, сопоставление USB-устройств и чтение регистров после записи. Сохранение IMOD-профиля адаптировано к новому драйверу. Добавлена настройка NIC ITR для распознанных сетевых контроллеров с отдельным сохранением профиля на следующий вход в Windows.
- Добавлены оценка частоты событий Raw Input и настройка `RawMouseThrottleDuration` для поддерживаемых сборок Windows 11.
- Добавлены резервные копии и восстановление выбранного снимка; запись настроек требует предварительного снимка согласно выбранному действию.
- Добавлено переключение RU/EN без перезапуска, переработаны карточки устройств и отчёты о применении настроек.

В релизе два EXE и `SHA256SUMS.txt`. `DEVICE.TWEAKER.exe` требует [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0); в `DEVICE.TWEAKER.SelfContained.exe` среда уже включена. `DTIMOD.sys` и KDU встроены в обе сборки.

## Изменения

- Добавлено масштабирование элементов интерфейса по DPI Windows.
- Уточнена классификация P/E-ядер по `EfficiencyClass` и наличию SMT для выбора CPU в интерфейсе и автооптимизации.
- Переработан порядок распределения логических процессоров между устройствами при автооптимизации.
- Убраны повторные строки в логе определения USB-ролей для альтернативных ключей одного контроллера.

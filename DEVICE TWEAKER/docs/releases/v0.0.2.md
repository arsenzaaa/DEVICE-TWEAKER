# Релиз DEVICE TWEAKER v0.0.2

## Что нового в этой версии

- **Оптимизация опроса устройств:** ускорено построение дерева топологии на системах с большим количеством PCIe-мостов и периферийных контроллеров.
- **Устранение дубликатов в логах:** исправлены повторяющиеся записи в журнале при классификации составных HID-устройств.
- **Стабильность работы с реестром:** улучшена предварительная валидация параметров устройств перед записью в системные разделы реестра.

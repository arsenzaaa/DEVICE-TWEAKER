# DEVICE TWEAKER v0.0.4

## Что изменилось после v0.0.3

- Исправлен запуск проверок интерфейса и скрипта публикации через Windows PowerShell 5.1: русские строки теперь читаются в правильной кодировке.
- Исправлена подсказка на русском языке для `Affinity Mask`; добавлен тест согласованности перевода.
- На странице проекта добавлены демонстрационные изображения интерфейса для GPU, USB/IMOD и сети.
- Приложение и установочные сведения обновлены до версии 0.0.4. Поведение настройки устройств не менялось.
- Сборка релиза привязана к тегу и исходному коммиту. Перед созданием черновика релиза выполняются тесты, сборка двух EXE и проверка их SHA-256.

В релизе два EXE и `SHA256SUMS.txt`. `DEVICE.TWEAKER.exe` требует [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0); `DEVICE.TWEAKER.SelfContained.exe` включает среду .NET. Драйвер и загрузчик встроены в обе сборки.

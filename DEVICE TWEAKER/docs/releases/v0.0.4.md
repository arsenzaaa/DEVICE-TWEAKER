## DEVICE TWEAKER 0.0.4

Большое обновление после 0.0.3.

- IRQ Mode с чтением данных Windows и уточнением MSI / MSI-X через DTIMOD.sys. Общая кнопка СЧИТАТЬ IRQ; открытие программы и обновление списка не загружают драйвер.
- Исправлено восстановление USB Selective Suspend в плане питания.
- Исправлены отображение частоты мыши и повторяющиеся подписи polling.
- Доработаны сохранённые профили IMOD / NIC ITR и диагностика RSS.
- Переработаны диалоги, восстановление бекапов, поля ввода и навигация с клавиатуры.
- Обновлены RU/EN, порядок ролей USB и цвета категорий.
- Добавлены идентификатор сборки и подробности чтения IRQ Mode / RSS в логах.
- Внутренняя логика разделена на отдельные компоненты. Проверки и тест-панель вынесены в dev/qa и не входят в обычный EXE.

[Полный список изменений](https://github.com/arsenzaaa/DEVICE-TWEAKER/blob/v0.0.4/CHANGELOG.md) · [English](https://github.com/arsenzaaa/DEVICE-TWEAKER/blob/v0.0.4/CHANGELOG.en.md) · [Скриншоты](https://github.com/arsenzaaa/DEVICE-TWEAKER/blob/v0.0.4/SCREENSHOTS.md)

## Скачать

- **DEVICE.TWEAKER.exe** требует [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0).
- **DEVICE.TWEAKER.SelfContained.exe** включает среду .NET.
- **DEVICE.TWEAKER.Source.v0.0.4.zip** содержит исходники, скрипты сборки и dev/qa.

SHA-256: `SHA256SUMS.txt` для EXE, `SOURCE-SHA256SUMS.txt` для архива исходников. DTIMOD.sys и загрузчик встроены в оба EXE.

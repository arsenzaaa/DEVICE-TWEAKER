# Релиз DEVICE TWEAKER v0.0.4-alpha.1

## Что нового в этой версии

- **Собственный Ring 0 драйвер DTIMOD.sys:** замена стороннего `winio.sys` на собственный подписанный драйвер (`\\.\DeviceTweakerImod2`) для прямого доступа к физической памяти через `MmMapIoSpace`. Обеспечена совместимость с изоляцией ядра Windows (HVCI / Memory Integrity) и античитами (Vanguard, EAC, BattlEye).
- **Прямое управление регистрами xHCI IMOD:** чтение и запись 32-битного регистра `IMOD` (квант 250 нс) хост-контроллеров USB xHCI через MMIO.
- **Классификация USB-контроллеров (UsbChipPath):** разделение шины на прямой процессорный корень (`CHIP 0` / Direct CPU Lanes) и чипсетные хабы (`CHIP 1` / PCH).
- **Профили устройств USB:** определение ролей подключенных устройств (мышь, клавиатура, аудиоинтерфейс, геймпад) для назначения профилей задержки IMOD.
- **Аппаратная модерация сетевых карт (NIC ITR):** прямое чтение и программирование аппаратных регистров Intel (EITR/ITR) и Realtek (IntrMit/IntrMitV2).
- **Архитектурная топология процессора:**
  - Определение гибридных CPU Intel (P-Cores / E-Cores) и кнопка быстрого выбора `[ Р-ЯДРА ]`.
  - Определение многочиплетных процессоров AMD Ryzen (Dual-CCD) с визуальной маркировкой ядер CCD1 и кнопка `[ CCD0 ]`.
  - Индикация статуса Hyper-Threading / SMT, CPPC и гибридной топологии в интерфейсе.
- **Система контрольных точек:** создание эталонного снимка `DeviceTweakerBackup_ORIGINAL.json` при первом запуске, сохранение контрольных точек локально или в `%AppData%\DEVICE TWEAKER`.
- **Raw Input:** определение частоты опроса (Polling Rate) мыши и клавиатуры через Win32 Raw Input API.

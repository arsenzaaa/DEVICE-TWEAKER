**DEVICE TWEAKER** — утилита для Windows 10 и 11, объединяющая настройку MSI Mode, привязку прерываний к ядрам (CPU Affinity), изоляцию через ReservedCpuSets, сетевой стек (RSS, NIC ITR) и прямое управление регистрами USB xHCI IMOD в едином интерфейсе с умной авто-оптимизацией.

---

## Зачем нужна настройка прерываний

- **Прерывания вытесняют игровой поток:** Обработчики прерываний (ISR) и очереди отложенных процедур (DPC) выполняются с наивысшим приоритетом ядра Windows. Если прерывания сетевой карты или высокочастотной мыши (1000–8000 Гц) обрабатываются на том же ядре, где выполняется игра, основной поток вытесняется, что приводит к микрофризам и нестабильному фреймтайму.
- **Разгрузка CPU 0:** Windows по умолчанию направляет на нулевое логическое ядро системный таймер, дисковые операции и прерывания устройств, создавая заторы в очередях DPC.
- **Аппаратная модерация USB (xHCI IMOD):** По умолчанию в xHCI контроллерах включена модерация прерываний (~50 мкс), которая накапливает пакеты от мыши и передает их пачками. Установка `0 мкс` через собственный драйвер `DTIMOD.sys` полностью отключает модерацию — прерывания мыши передаются процессору мгновенно.
- **Учет архитектуры процессора:** Исключение медленных E-ядер на процессорах Intel и фиксация прерываний критических устройств на чиплете с 3D V-Cache (CCD0) на процессорах AMD Ryzen, чтобы избежать лишних задержек при передаче данных через Infinity Fabric.

## Возможности

- **Группировка и мониторинг устройств:** видеокарты, USB-контроллеры, сетевые адаптеры, накопители и аудиоустройства разделены по отдельным блокам с отображением их текущих параметров.
- **MSI / MSI-X и IRQ Priority:** включение режима прерываний по сообщению (Message Signaled Interrupts), снятие ограничения лимита векторов (`MessageNumberLimit`) и выставление наивысшего приоритета обслуживания (`IRQ Priority = High`).
- **Распределение CPU Affinity:** ручная и автоматическая привязка прерываний устройств к физическим ядрам и потокам с наглядной картой: разделение P-Core / E-Core, пары Hyper-Threading / SMT, чиплеты AMD (CCD0 / CCD1), кластеры CCX и системный приоритет ядер (CPPC).
- **Прямое управление USB xHCI IMOD через `DTIMOD.sys`:** чтение и запись физических регистров модерации прерываний (MMIO) контроллеров USB с шагом 250 нс. Позволяет установить `0 мкс` (без задержки) для мыши или настроить индивидуальные интервалы для каждого интерраптера.
- **Оптимизация сетевого стека (RSS и NIC ITR):** отключение модерации прерываний сетевой карты (`ITR = 0 / Off` для адаптеров Intel и Realtek), настройка очередей Receive Side Scaling (RSS) и отключение Energy Efficient Ethernet (EEE).
- **Системная изоляция ядер (`ReservedCpuSets`):** настройка системной маски `ReservedCpuSets` на уровне ядра Windows. На зарезервированные ядра перестают назначаться фоновые службы и системные потоки ОС.
- **Авто-оптимизация под топологию CPU в 1 клик:**
  - Полная разгрузка `CPU 0` от игровых контроллеров и периферии.
  - Закрепление видеокарты за парой физических P-ядер.
  - Разведение мыши и сетевой карты по разным ядрам во избежание пересечения очередей DPC.
  - Фиксация прерываний на чиплете с 3D V-Cache (CCD0) для процессоров AMD Ryzen X3D.
- **Управление энергосбережением:** быстрое отключение Power Saving и Selective Suspend для USB-контроллеров и проводных сетевых адаптеров.
- **Классификация USB-контроллеров:** определение CHIP 0 / CHIP 1 по PCI ID и фильтрация контроллеров NVIDIA.
- **Безопасность и резервные копии:** автоматическое создание бекапа перед применением любых настроек, защита заводского снимка Windows (ORIGINAL STATE) от перезаписи и возможность полного отката.
- **Локализация:** поддержка русского и английского интерфейса с переключением на лету без перезапуска.

## Важно

- Программа изменяет параметры прерываний в реестре (`HKLM`) и при работе с IMOD использует драйвер `DTIMOD.sys`.
- Кнопка **REFRESH (ОБНОВИТЬ)** опрашивает устройства через SetupAPI и реестр без загрузки драйвера в ядро.
- Драйвер `DTIMOD.sys` задействуется только при нажатии **CHECK (ПРОВЕРИТЬ)** или сохранении значений IMOD. Загруженный через KDU драйвер остается в памяти до перезагрузки Windows во избежание сбоев ядра при выгрузке.
- Для вступления изменений в силу после применения настроек требуется перезагрузка ПК.
- Логи работы создаются автоматически при каждом запуске в папке `logs` рядом с исполняемым файлом.

## Требования

- Windows 10 или Windows 11 (64-bit).
- Варианты сборки:
  - `DEVICE.TWEAKER.exe` (~4 МБ) — стандартная версия, требует установленный [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
  - `DEVICE.TWEAKER.NET.FRAMEWORK.exe` (~150 МБ) — автономная сборка со встроенным рантаймом .NET 8 (работает сразу на любой чистой системе без доустановки библиотек).

## Запуск и использование

1. Скачайте свежий релиз со страницы [GitHub Releases](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases).
2. Запустите программу от имени **Администратора**.
3. Ознакомьтесь со списком обнаруженных устройств и текущей раскладкой ядер.
4. Нажмите **АВТООПТИМИЗАЦИЯ** для автоматического подбора под ваш процессор либо распределите прерывания вручную.
5. Нажмите **ПРИМЕНИТЬ**.
6. Перезагрузите компьютер.

## Сборка из исходного кода

Для компиляции необходим [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Сборка обеих версий приложения одной командой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Flavor both -Configuration Release -SkipImodDriverBuild
```

Готовые исполняемые файлы и контрольные суммы SHA-256 сформируются в каталоге `bin\ReleasePackages\<версия>\`.

## Структура проекта

- `Affinity` — привязка прерываний (CPU Affinity), сетевые очереди RSS и маска ReservedCpuSets.
- `Core` — управление службами, резервные копии, восстановление и логика IMOD.
- `Devices` — опрос устройств PCI/PCI-e, USB-контроллеров и сетевых адаптеров NDIS.
- `GUI` — графический интерфейс WinForms, кастомные элементы и диалоговые окна.
- `IMOD` — драйвер прямого доступа `DTIMOD.sys` и библиотека KDU.
- `Localization` — файлы локализации (русский и английский языки).
- `Tweaks` — алгоритм авто-оптимизации под топологию CPU и сброс настроек.

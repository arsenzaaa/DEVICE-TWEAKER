# Безопасность

DEVICE TWEAKER - системная утилита с правами администратора. Она может выполнять следующие действия.

- изменять параметры MSI и политики распределения прерываний в `HKLM`.
- изменять `ReservedCpuSets`.
- настраивать RSS и ITR у поддерживаемых сетевых адаптеров.
- загружать драйвер `DTIMOD.sys` через KDU для управления USB IMOD.
- запускать необходимые компоненты из `IMOD/KDU`.

Драйвер, загруженный через KDU, намеренно остается в памяти до перезагрузки Windows. Принудительная выгрузка не выполняется, так как на части систем она может привести к BSOD.

## Рекомендации

- Скачивайте программу только из официального репозитория или собирайте ее самостоятельно.
- Перед применением настроек создавайте резервную копию.
- Не устанавливайте случайные или измененные версии `DTIMOD.sys`.
- Не распространяйте неподписанные сборки драйвера как безопасные публичные релизы.
- Проверяйте контрольные суммы файлов из GitHub Releases.
- `DTIMOD.sys` подписан сертификатом разработчика `CN=MADE BY ARSENZA`. Этот сертификат не входит в публично доверенные корневые центры Windows.
- Windows Security может заблокировать драйвер или компоненты KDU. Не добавляйте исключения безопасности для файлов из неизвестных источников.

## Сообщение об уязвимости

Не публикуйте в открытом GitHub Issue рабочий способ эксплуатации ошибки в драйвере или повышения привилегий.

Свяжитесь со мной через [Telegram @arsenzaa](https://t.me/arsenzaa) и укажите следующие данные.

- версию Windows.
- версию DEVICE TWEAKER.
- последовательность действий для воспроизведения.
- использовался ли измененный или самостоятельно собранный драйвер.

Ошибки, вызванные намеренной установкой слишком агрессивных значений Affinity, IMOD или ITR на собственном компьютере, сами по себе не считаются уязвимостью.

# История изменений

## v0.0.4-alpha.2 (22.09.2026)

### Драйвер и сканирование устройств
- Сканирование списка устройств (кнопка `REFRESH`) отделено от аппаратного опроса контроллеров (кнопка `CHECK`). Обычное обновление работает исключительно через SetupAPI и системный реестр без обращения к Ring 0 драйверу.
- Для чтения и валидации физических регистров xHCI IMOD и сетевых карт NIC ITR добавлена отдельная кнопка `CHECK`.
- Добавлена предварительная проверка размера PCI BAR, версии xHCI и границ адресного пространства MMIO перед чтением. Неподдерживаемые контроллеры безопасно пропускаются.
- Добавлены аппаратные профили для сетевых адаптеров Intel Ethernet I225-K (Device ID `15F7`) и I225-I (Device ID `15F8`) в дополнение к существующим линейкам I210/I211, I225-V/LM, I226 и I350.
- Добавлена диагностика статуса Microsoft Vulnerable Driver Blocklist: при блокировке загрузки драйвера выводится информативное предупреждение с описанием влияния на соревновательные античиты.

### Топология процессора и планировщик
- Получение аппаратных рейтингов качества кремния ядер переведено на прямое чтение событий ядра Windows ETW (провайдер `Microsoft-Windows-Kernel-Processor-Power`, Event ID 55, поле `MaximumPerformancePercent`). Время опроса топологии сократилось с 2500 мс до менее 60 мс.
- Доработана логика авто-оптимизации очередей (кнопка `АВТООПТИМИЗАЦИЯ`):
  - Видеокарта фиксируется на паре соседних физических P-ядер с обязательным пропуском системного ядра CPU 0.
  - Очереди мыши и сетевой стек разводятся по независимым физическим ядрам для исключения взаимных блокировок DPC.
  - На процессорах Intel Core Hybrid высокочастотные прерывания изолируются от энергоэффективных E-ядер.
  - Интегрированное видеоядро (iGPU) переводится в режим MSI со сбросом маски Affinity на значения по умолчанию.
- При ручном выборе ядер чекбоксами параметр `DevicePolicy` автоматически переключается на `SpecCPU` (4). При снятии всех отметок восстанавливается `MachineDefault` с удалением параметра `AssignmentSetOverride` из реестра.
- Для параметра MSI Limit (`MessageNumberLimit`) значение `0` или пустое поле теперь удаляет параметр из реестра, разблокируя полный аппаратный пул векторов MSI-X контроллера (до 2048 векторов).

### Безопасность и точки восстановления
- Создание эталонного снимка системы (`DeviceTweakerBackup_ORIGINAL.json`) при первом запуске программы с блокировкой от перезаписи.
- Обязательное создание контрольной точки перед выполнением операций `APPLY`, `AUTO-OPTIMIZATION`, `RESET WINDOWS DEFAULT`, а также перед записью `IMOD` и `NIC ITR`. Операция отменяется, если контрольную точку создать не удалось.
- Атомарный откат изменений при возникновении ошибок записи в реестр во время применения настроек.

### Интерфейс и удобство
- Добавлен переключатель языка интерфейса EN / RU на лету без перезапуска программы (`UiLanguage`).
- Добавлена настройка параметра `HKCU\Control Panel\Mouse\RawMouseThrottleDuration` для сборок Windows 11 22H2 (build 22621.1928+) и новее с контролем версии ОС.
- Переработаны диалоговые окна отчетов для операций `APPLY`, `AUTO-OPTIMIZATION` и `RESTORE` с цветовой индикацией статуса каждого шага и ссылками на лог-файлы.
- Добавлены кастомные компоненты интерфейса (`ThemedButton`, `ThemedDialogForm`, `ThemedNumericUpDown`, `ThemedTextBox`, `ThemedToolTip`).

### Тестирование и надежность
- Разработан набор модульных тестов xUnit (41 тест), покрывающий парсинг масок Affinity, расчет профилей NIC ITR, кодирование и декодирование параметра `ReservedCpuSets`, а также классификацию контроллеров USB (`UsbChipPath`).
- Добавлена проверка контрольных сумм SHA-256 встроенных библиотек и драйверов перед инициализацией.

## v0.0.4-alpha.1 (12.03.2026)

- Замена драйвера `winio.sys` на собственный подписанный Ring 0 драйвер `DTIMOD.sys` (`\\.\DeviceTweakerImod2`) для прямого доступа к физической памяти через `MmMapIoSpace`. Обеспечена совместимость с изоляцией ядра Windows (HVCI / Memory Integrity) и античитами (Vanguard, EAC, BattlEye).
- Реализовано прямое чтение и редактирование 32-битного регистра `IMOD` (квант 250 нс) хост-контроллеров USB xHCI через MMIO.
- Классификация USB-контроллеров по топологии шины PCIe: разделение прямого процессорного корня (`CHIP 0` / Direct CPU Lanes) и чипсетных хабов (`CHIP 1` / PCH).
- Определение ролей подключенных USB-устройств (мышь, клавиатура, аудиоинтерфейс, геймпад) для назначения профилей задержки IMOD.
- Прямое чтение и программирование аппаратных регистров модерации прерываний сетевых адаптеров Intel (EITR/ITR) и Realtek (IntrMit/IntrMitV2).
- Архитектурная топология процессора:
  - Определение гибридных CPU Intel (P-Cores / E-Cores) и добавление кнопки быстрого выбора `[ Р-ЯДРА ]`.
  - Определение многочиплетных процессоров AMD Ryzen (Dual-CCD) с визуальной маркировкой ядер CCD1 и добавлением кнопки `[ CCD0 ]`.
  - Индикация статуса Hyper-Threading / SMT, CPPC и гибридной топологии в шапке приложения.
- Механизм дифференциальных контрольных точек с поддержкой сохранения в каталоге программы или в `%AppData%\DEVICE TWEAKER`.
- Определение фактической частоты опроса (Polling Rate) мыши и клавиатуры через Win32 Raw Input API.

## v0.0.3 (17.02.2026)

- Добавлена настройка очередей Receive Side Scaling (RSS) для сетевых адаптеров NDIS: управление лимитом очередей (`*NumRssQueues`) и базовым ядром обработки (`*RssBaseProcNumber`).
- Скорректирован приоритет авто-оптимизации очередей для сетевых устройств.
- Улучшена категоризация и фильтрация устройств в списке (USB/HID, Display, Audio, Storage).
- Расширено диагностическое логирование операций с устройствами и кодов ошибок SetupAPI.

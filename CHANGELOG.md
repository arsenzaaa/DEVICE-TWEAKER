# История изменений

[English](./CHANGELOG.en.md) · [DEVICE TWEAKER](./README.md)

## [0.0.4](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.4) · 1 октября 2026

В этот раз новые настройки устройств не добавлял. Что изменилось:

- Исправил русскую подсказку для Affinity Mask и добавил проверку перевода.
- Поправил запуск проверок интерфейса и сборки через Windows PowerShell 5.1: русские строки больше не ломаются из-за кодировки.
- Привязал сборку релиза к тегу и исходному коммиту. Перед черновиком релиза запускаются тесты, собираются оба EXE и проверяются их SHA-256.
- Обновил номер версии в программе и сведения о выпуске.
- Переснял главный скриншот: на Intel Core i9-14900K открыт блок IMOD. В галерее показаны AMD с таблицей IMOD, Intel с видеокартой и AMD с NIC ITR. Все значения демонстрационные, настройки в систему не записывались.
- Убрал графические кнопки из README. Ссылки остались обычным текстом.

Логика настройки устройств в этом выпуске не менялась.

## [0.0.3](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.3) · 1 октября 2026

Большое обновление после 0.0.2:

- Перевёл xHCI IMOD с WinIO на DTIMOD.sys и KDU. Теперь можно смотреть значения по interrupter, настраивать контроллер целиком или по индексам, сопоставлять USB-устройства и перечитывать регистры после записи. Сохранённый профиль тоже переведён на новый драйвер.
- Добавил NIC ITR для распознанных Intel и Realtek: чтение и запись регистров, данные по очередям и профиль для следующего входа в Windows. Для неизвестного PCI ID запись недоступна.
- Переписал автооптимизацию под физические ядра, P/E-cores, SMT/HT, CPPC и AMD CCD/CCX. Для GPU выбираются два разных физических ядра. Если роль устройства или топология CPU определены ненадёжно, программа пропускает назначение и пишет причину.
- Добавил число RSS-очередей к выбору базового CPU. Сохранённые настройки и активное состояние Get-NetAdapterRss теперь показаны отдельно.
- Разделил настройку MSI Mode, оценку режима по выделенным IRQ и аппаратные возможности устройства. Оценка по IRQ остаётся подсказкой: отличить MSI от MSI-X по ней нельзя.
- Добавил Unlimited для MSI Limit и проверку числового значения по возможностям устройства, если их удалось определить. Пустая маска обычного устройства возвращает MachineDefault и удаляет AssignmentSetOverride.
- Исправил соответствие AllClose и All значениям DevicePolicy: 1 и 3. В 0.0.2 подписи были перепутаны.
- Добавил оценку частоты событий мыши и клавиатуры по Raw Input и настройку RawMouseThrottleDuration на поддерживаемых сборках Windows 11. Это настройка фоновых обработчиков Raw Input, а не USB polling rate.
- Добавил настройки энергосбережения USB-контроллера и корневых хабов. Для проводной сети можно менять разрешение Windows отключать адаптер ради экономии энергии.
- Поправил распознавание HDMI/DisplayPort и S/PDIF-аудио. USB-контроллер с собственной политикой Interrupt Affinity остаётся в списке, даже если роль HID не определилась.
- Добавил переключение RU/EN без перезапуска, переработал отображение устройств, блоки IMOD/ITR и переходы по категориям.
- Переработал бекапы: выбор папки, восстановление конкретной копии, удаление старых копий и сброс настроек. Перед ручным применением, записью IMOD/ITR и сбросом нужна проверенная копия; автооптимизация сначала сохраняет исходные настройки.
- В отчёте теперь видно, что применилось, что пропущено и где возникла ошибка. Обычное обновление списка не загружает драйвер; кнопка ПРОВЕРИТЬ перечитывает регистры.

Примечание к архивному выпуску: тег v0.0.3 перенесли уже после публикации EXE. Поэтому исходники по тегу не полностью совпадают с опубликованными файлами. В [v0.0.4](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.4) исходный коммит указан прямо в описании релиза.

## [0.0.2](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.2) · 15 января 2026

После 0.0.1:

- Добавил масштабирование интерфейса по DPI Windows.
- Поправил определение P/E-ядер по EfficiencyClass и SMT для списка CPU и автооптимизации.
- Изменил порядок распределения CPU между устройствами при автооптимизации.
- Убрал повторяющиеся строки об USB-ролях одного контроллера из лога.

## [0.0.1](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.1) · 14 января 2026

Первый публичный выпуск для Windows 10/11 x64: MSI Mode и Limit, IRQ Priority, Interrupt Affinity, ReservedCpuSets, базовый CPU для RSS и xHCI IMOD через WinIO. Тёмный интерфейс показывает список устройств и позволяет искать по нему.

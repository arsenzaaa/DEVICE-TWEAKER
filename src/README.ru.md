# src

[English](./README.md) | **Русский**

Исходники DEVICE TWEAKER. [Сборка и устройство проекта](../docs/DEVELOPMENT.ru.md).

- `Affinity` - топология CPU, affinity, ReservedCpuSets.
- `Devices` - обнаружение устройств, RSS, энергосбережение.
- `Core` - применение, восстановление, IMOD, NIC ITR, автозапуск.
- `GUI`, `Localization` - интерфейс и строки RU/EN.
- `Interop` - Windows API.
- `Startup` - скрипт автозапуска и общий код доступа к регистрам.
- `IMOD` - драйвер DTIMOD и загрузчик KDU.

# KDU

В приложение встроена пара `kdu.exe` / `drv64.dll` версии **1.4.5.2512** из [коммита DEVICE TWEAKER 6094c866](https://github.com/arsenzaaa/DEVICE-TWEAKER/commit/6094c866ac2d8baaf362d393f4911b76a4fc7908), на который указывал тег `v0.0.4` при импорте. Точное происхождение и SHA-256 указаны в `../Loader/KDU.build.json`.

Здесь сохранено соответствующее дерево исходников из того же коммита. Репозиторий, коммит и хеши входных файлов находятся в `upstream.json`. Документация автора: [README.upstream.md](README.upstream.md). Лицензия MIT: [LICENSE.txt](LICENSE.txt).

`build-kdu.ps1` собирает копию исходников под `bin/KduBuild`. Готовая пара в `IMOD/Loader` закреплена отдельно; обычная сборка приложения её не пересобирает. Скрипт не заменяет её автоматически. Совпадение байтов новой компиляции с опубликованными файлами не заявляется.

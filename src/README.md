# src

**English** | [Русский](./README.ru.md)

DEVICE TWEAKER source code. [Build instructions and code structure](../docs/DEVELOPMENT.md).

- `Affinity` - CPU topology, affinity, ReservedCpuSets.
- `Devices` - device discovery, RSS, power saving.
- `Core` - apply, restore, IMOD, NIC ITR, startup.
- `GUI`, `Localization` - user interface and RU/EN strings.
- `Interop` - Windows API.
- `Startup` - startup script and shared register-access code.
- `IMOD` - DTIMOD driver and KDU loader.

# DEVICE TWEAKER 0.1.0

[Release notes](./README.md) · [Русский](./v0.1.0.ru.md)

First release of **DEVICE TWEAKER REWORK**.

## What changed

- **Interface and responsiveness.** **REFRESH** rescans devices and reuses compatible cards while keeping edits, focus and scroll position. Moved Raw Input (`WM_INPUT`) off the UI window onto a dedicated background thread so 1K–8K devices stay responsive and closing the window is immediate. Added short smooth UI transitions on a shared frame clock, localized in-progress button captions with adaptive wrapping on narrow/high-DPI layouts, and Core / Core/SMT labels on homogeneous CPUs. Device discovery continues if Windows Storage WMI (`MSFT_PhysicalDisk`) is unavailable.
- **USB IMOD.** **SET** applies to the selected controller; **SET**, **APPLY** and **AUTO-OPTIMIZATION** automatically expand the interrupter readback details table on updated controllers. A failed or partial register write keeps the previous startup profile. **DELETE PROFILE** backs up and removes the shared USB IMOD and NIC ITR profile. Restart Windows to clear active register overrides.
- **Networking.** RSS queue choices follow the driver even on adapters without MSI-X. Corrected NIC ITR layouts for Killer E3000 (`10EC:3000`) and RTL8118AS (`10EC:8162`). Save NIC ITR again for these adapters if [restore skips an older entry](../guide/06-network.md#nic-itr).
- **Affinity and readback.** Windows-selected affinity policies save without a manual CPU mask. Reading `AssignmentSetOverride` supports short (1–7 byte) `REG_BINARY` masks in addition to 4- and 8-byte values. The RSS log compares the queue count, processor count and both ends of the CPU range, including processor groups, with the active configuration.
- **Saved profiles.** Each NIC ITR entry targets a specific PCI device instance. Startup skips older entries that match multiple adapters. A register write failure appears in the startup log and the task result. A disabled task stays disabled when you save a profile.
- **Restore.** If a backup lists a startup profile but its contents are missing, restore stops before writing settings. A refresh error after restoration is reported separately.
- **Driver and startup.** DTIMOD checks register access against the selected device's resources. The app verifies the driver file before loading and restores the previous startup files and task if an update fails. If an older DTIMOD build is loaded, restart Windows before using the updated driver.

Requires Windows 10/11 x64 and administrator access.

IMOD and NIC ITR depend on controller/adapter support. DTIMOD can conflict with anti-cheat software. See the [driver guide](../guide/11-driver.md) for loading requirements, startup behavior and the PnP/power limitation.

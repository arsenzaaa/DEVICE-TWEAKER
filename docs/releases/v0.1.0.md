# DEVICE TWEAKER 0.1.0

[Release notes](./README.md) · [Русский](./v0.1.0.ru.md)

Initial release of **DEVICE TWEAKER REWORK**.

Device interrupt configuration, CPU affinity and USB/network tuning in one portable Windows utility.

## Highlights

- **Restricted driver access.** Device-scoped MMIO reads and PCI-class checks replace the unrestricted physical-memory read request. A separate xHCI query preserves the exact USB interrupter map without exposing raw context memory.
- **Refresh and animation work.** Compatible cards are reused after a fresh scan. Mouse event-rate estimates are recalculated when samples change, and the shared animation clock stops when idle.
- **Startup and diagnostics.** Task registration verifies the stored action and uses a protected XML location. Incomplete IMOD reads no longer relabel interrupters; missed Russian translations in restore and scan results are filled in.
- **Code organization and QA.** Startup files, backups, USB role mapping, driver files and the KDU process have dedicated components. The source includes read-only models and GUI scenarios, with serialized execution and memory limits.

The [changelog](../../CHANGELOG.md) covers the release in more detail. The [guide](../guide/README.md) explains individual settings and verification.

## Upgrading from 0.0.x

Profile and backup formats are preserved. An already loaded older DTIMOD requires a Windows restart before the updated hardware interface can be used. Verify the saved profile and register readback with the new build.

## Files

- `DEVICE.TWEAKER.SelfContained.exe` includes the .NET runtime.
- `DEVICE.TWEAKER.exe` requires .NET 10 Desktop Runtime x64.

Windows 10/11 x64 and administrator access are required. Both EXEs contain the same application and embedded hardware components.

## Hardware support

IMOD and NIC ITR depend on controller/adapter support. DTIMOD can conflict with anti-cheat software; [driver requirements and limitations](../guide/11-driver.md) apply. Model-based QA does not establish compatibility with every physical system or Windows PnP transition.

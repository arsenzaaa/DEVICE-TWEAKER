# DEVICE TWEAKER 0.1.0

[Release notes](./README.md) · [Русский](./v0.1.0.ru.md)

First release of **DEVICE TWEAKER REWORK**, with updates to device refresh, input handling, saved profiles and the DTIMOD interface.

## Updated 17 November 2026

- Homogeneous CPUs use Core and Core/SMT labels; hybrid P/E labels and core-allocation rules are unchanged.
- RSS queue count is tracked separately from processor count. Driver-advertised queue options remain available on adapters without MSI-X; AUTO retains its single-queue profile.
- Revised the English and Russian guide, settings reference and interface examples.

## Interface and responsiveness

- REFRESH performs a fresh device scan and reuses compatible cards, preserving pending edits, focus and scroll position.
- Mouse event-rate calculations reuse unchanged samples. Animations share a clock that stops when idle.
- Result, information and backup-location dialogs have centered action rows. Restore, scan and power-plan messages now include the missing Russian translations.
- NIC ITR readback preserves edits made while the automatic backup is being created. A second launch no longer selects an unrelated Explorer window.

## Saved profiles and diagnostics

Startup-task registration checks the stored command and arguments. If registration fails, the previous USB IMOD / NIC ITR profile is retained. Profile and backup formats are preserved.

An incomplete IMOD readback is reported with the failed interrupter index and address, without shifting the remaining values into the wrong rows.

Corrected NIC ITR register layouts for Killer E3000 (`10EC:3000`) and RTL8118AS (`10EC:8162`). Restore skips incompatible saved entries with a warning and preserves the remaining supported settings. Save NIC ITR again for affected adapters. See [NIC ITR compatibility](../guide/06-network.md#nic-itr).

## Driver changes

DTIMOD register reads and writes are bound to the selected PCI device and its allocated MMIO ranges, and limited to xHCI and Ethernet classes. The general physical-memory read request is removed. A separate controller query preserves the exact USB interrupter map.

NIC ITR resolves its register bank from PCI configuration, verifies Windows-allocated ranges and rejects MSI-X table/PBA overlap.

If an older DTIMOD is already loaded, restart Windows before using the updated driver interface.

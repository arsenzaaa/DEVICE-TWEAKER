# DEVICE TWEAKER 0.0.1

[Release notes](./README.md) · [Русский](./v0.0.1.ru.md)

Initial release of **DEVICE TWEAKER REWORK**.

Device interrupt configuration, CPU affinity and USB/network tuning in one portable Windows utility.

## Highlights

- **Manual configuration and AUTO.** Adjust MSI, IRQ Priority and interrupt affinity, or select cores automatically using the CPU topology. ReservedCpuSets and RSS processors/queues have separate controls.
- **IMOD and NIC ITR.** Configure supported USB controllers and network adapters, read register values back and save profiles for sign-in, resume and supported device-connection events.
- **An English/Russian interface.** Search and category filters help navigate devices. REFRESH rescans the system and reuses compatible cards while preserving applicable pending edits and scroll position.
- **Backup and diagnostics.** Preserve original settings, restore saved snapshots and inspect operation reports and detailed logs, including partial results and errors.

The [changelog](../../CHANGELOG.md) covers the release in more detail. The [guide](../guide/README.md) explains individual settings and verification.

## Files

- `DEVICE.TWEAKER.SelfContained.exe` includes the .NET runtime.
- `DEVICE.TWEAKER.exe` requires .NET 10 Desktop Runtime x64.

Windows 10/11 x64 and administrator access are required. Both EXEs contain the same application and embedded hardware components.

## Hardware support

IMOD and NIC ITR depend on controller/adapter support. DTIMOD can conflict with anti-cheat software; [driver requirements and limitations](../guide/11-driver.md) apply. Model-based QA does not establish compatibility with every physical system or Windows PnP transition.

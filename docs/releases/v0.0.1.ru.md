# DEVICE TWEAKER 0.0.1

[Описания выпусков](./README.ru.md) · [English](./v0.0.1.md)

Первый выпуск Rework.

Настройка CPU affinity прерываний, MSI, USB IMOD и поддерживаемой модерации прерываний сети в переносимом интерфейсе Windows. Включены AUTO с учётом топологии CPU, управление RSS, бекапы и восстановление, сохранённые профили и подробные логи операций.

Состав первого выпуска описан в [истории изменений](../../CHANGELOG.ru.md), отдельные настройки - в [руководстве](../guide/README.ru.md).

## Файлы

- `DEVICE.TWEAKER.SelfContained.exe` включает .NET.
- `DEVICE.TWEAKER.exe` требует .NET 10 Desktop Runtime x64.

Нужны Windows 10/11 x64 и права администратора. Оба EXE содержат одно приложение и одинаковые встроенные аппаратные компоненты.

## Поддержка оборудования

IMOD и NIC ITR зависят от возможностей контроллера или адаптера. DTIMOD может конфликтовать с античитами; действуют [требования и ограничения драйвера](../guide/11-driver.ru.md). Модельный QA не подтверждает совместимость со всеми физическими системами и переходами Windows PnP.

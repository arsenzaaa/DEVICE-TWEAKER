## Изменения

- Добавлено масштабирование интерфейса по DPI Windows.
- Определение P/E-ядер для списка CPU и AUTO теперь учитывает EfficiencyClass вместе с наличием SMT.
- Изменён порядок распределения CPU между устройствами в AUTO.
- В логе больше не дублируются USB-роли одного контроллера, найденного по разным ключам.

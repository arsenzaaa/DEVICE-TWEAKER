Большое обновление после 0.0.3: автозапуск IMOD и NIC ITR через Планировщик заданий, чтение режима прерываний, RSS по физическим ядрам и более строгий драйвер DTIMOD.sys.

## Какой файл скачать

- **DEVICE.TWEAKER.SelfContained.exe** работает сразу, .NET уже внутри.
- **DEVICE.TWEAKER.exe** меньше по размеру, но нужен [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0).
- **DEVICE.TWEAKER.Source.v0.0.4.zip** содержит исходники, скрипты сборки и тесты.

Запускайте от имени администратора. DTIMOD.sys и загрузчик KDU встроены в обе сборки. Контрольные суммы лежат в `SHA256SUMS.txt` и `SOURCE-SHA256SUMS.txt`.

## Что нового

- **Автозапуск через Планировщик заданий.** Настройки IMOD и NIC ITR применяются при входе в Windows, после выхода из сна и при подключении USB. Раньше только при входе. Скрипт открытый и работает без EXE, файлы перед запуском сверяются по SHA-256.
- **IRQ Mode.** Настройка MSI Mode, текущий режим прерываний и возможности устройства показаны отдельно. Кнопка **СЧИТАТЬ IRQ** уточняет режим по конфигурации PCI.
- **RSS по физическим ядрам.** Соседи по SMT пропускаются, число очередей ограничено тем, что поддерживает драйвер.
- **NIC ITR без конфликтов.** Кнопка **СОХРАНИТЬ** выключает собственную модерацию драйвера, которая раньше перезаписывала значение регистра.
- **Проверка системы перед IMOD.** Программа показывает состояние Blocklist, HVCI, Microsoft Defender и служб FACEIT / Vanguard.

## Исправления

- Автозапуск брал interrupter устройства не из того места и после перезагрузки мог раскладывать роли иначе, чем программа. Теперь у них общий код.
- USB Selective Suspend восстанавливается из бекапа через Windows Power API, отдельно для сети и батареи.
- Polling Rate мыши показывает измеренную частоту, даже если она ниже максимума USB.
- Исправлены обрезка текста, переносы в диалогах, навигация с клавиатуры и белая вспышка при чтении IRQ Mode.

## Безопасность

- DTIMOD.sys записывает только в память, которую Windows выделила выбранному устройству. Прежняя общая запись в физическую память удалена.
- Перед каждым применением создаётся проверенный бекап. Файлы автозапуска могут изменять только администраторы и SYSTEM.

# DEVICE TWEAKER 0.1.0

[Описания выпусков](./README.ru.md) · [English](./v0.1.0.md)

Первый выпуск **DEVICE TWEAKER REWORK** с обновлённой работой REFRESH, обработкой ввода, сохранением профилей и интерфейсом DTIMOD.

## Обновлено 17 ноября 2026

- На однородных CPU используются подписи Core и Core/SMT. Подписи гибридных P/E-ядер и правила распределения ядер сохранены.
- Число RSS-очередей учитывается отдельно от числа процессоров. Для адаптеров без MSI-X сохранены варианты, объявленные драйвером; AUTO по-прежнему выбирает одну очередь.
- Переработаны английский и русский гайд, справочник настроек и примеры интерфейса.

## Интерфейс и отзывчивость

- REFRESH заново обнаруживает устройства и переиспользует совместимые карточки, сохраняя неприменённые правки, фокус и положение прокрутки.
- Расчёт частоты событий мыши переиспользует результат, пока измерения не изменились. Анимации используют общий генератор кадров, который останавливается в покое.
- Кнопки в окнах результата, сообщений и выбора места бэкапа выровнены по центру. Дополнены русские переводы результатов восстановления, ошибок обнаружения устройств и диагностики схем питания.
- Чтение NIC ITR сохраняет правки, сделанные во время создания автоматического бэкапа. Повторный запуск программы больше не выбирает постороннее окно Проводника.

## Сохранённые профили и диагностика

При регистрации задачи автозапуска проверяются сохранённая команда и аргументы. Если регистрация завершается ошибкой, прежний профиль USB IMOD / NIC ITR сохраняется. Форматы профилей и резервных копий не изменились.

При неполном чтении IMOD в лог записываются индекс interrupter и адрес сбоя. Остальные значения больше не сдвигаются в строки с неверными номерами.

Исправлены схемы регистров NIC ITR для Killer E3000 (`10EC:3000`) и RTL8118AS (`10EC:8162`). Восстановление пропускает несовместимые записи с предупреждением, сохраняя остальные поддерживаемые настройки. Для затронутых адаптеров сохраните NIC ITR заново. Подробнее в [разделе NIC ITR](../guide/06-network.ru.md#nic-itr).

## Изменения драйвера

Чтение и запись регистров DTIMOD привязаны к выбранному PCI-устройству и выделенным ему диапазонам MMIO. Эти операции разрешены только для классов xHCI и Ethernet. Общий запрос чтения физической памяти удалён; точная карта interrupter USB сохранена через отдельный запрос к контроллеру.

NIC ITR определяет базу регистров по конфигурации PCI, проверяет выделенные Windows диапазоны и исключает пересечение с таблицей/PBA MSI-X.

Если старый DTIMOD уже загружен, перед использованием обновлённого интерфейса драйвера перезагрузите Windows.

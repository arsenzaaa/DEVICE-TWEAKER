# DEVICE TWEAKER 0.1.0

[Описания выпусков](./README.ru.md) · [English](./v0.1.0.md)

Первый выпуск **DEVICE TWEAKER REWORK**.

## Что изменилось

- **Интерфейс и отзывчивость.** Кнопка **ОБНОВИТЬ** заново сканирует устройства, сохраняя правки, фокус и положение прокрутки на совместимых карточках. Приём Raw Input (`WM_INPUT`) вынесен в отдельный фоновый поток — интерфейс и закрытие окна не подвисают на устройствах 1K–8K. Кнопки аккуратно снимают фокус во время операций, русские подписи помещаются без обрезания, а на однородных процессорах используются подписи Core и Core/SMT. Обнаружение устройств продолжается, если WMI-класс Windows Storage (`MSFT_PhysicalDisk`) недоступен.
- **USB IMOD.** Кнопка **ЗАДАТЬ** применяется к выбранному контроллеру; после **ЗАДАТЬ**, **ПРИМЕНИТЬ** и **АВТООПТИМИЗАЦИИ** таблица подробностей по interrupter раскрывается автоматически. При ошибке или частичной записи регистров остаётся прежний профиль автозапуска. **УДАЛИТЬ ПРОФИЛЬ** создаёт резервную копию и удаляет общий профиль USB IMOD и NIC ITR. Для сброса действующих значений регистров перезагрузите Windows.
- **Сеть.** Выбор очередей RSS учитывает варианты драйвера и у адаптеров без MSI-X. Исправлены схемы регистров NIC ITR для Killer E3000 (`10EC:3000`) и RTL8118AS (`10EC:8162`). Сохраните NIC ITR заново, если [восстановление пропустило старую запись](../guide/06-network.ru.md#nic-itr).
- **Привязка и проверка.** Политики, при которых CPU выбирает Windows, сохраняются без ручной маски. Чтение `AssignmentSetOverride` поддерживает короткие (1–7 байт) маски `REG_BINARY` наряду со значениями длиной 4 и 8 байт. Лог RSS сверяет с действующей конфигурацией число очередей, число процессоров и обе границы диапазона CPU (с учётом групп процессоров).
- **Сохранённые профили.** Каждая запись NIC ITR привязана к конкретному экземпляру PCI-устройства. Автозапуск пропускает старые записи, которые подходят нескольким адаптерам. Ошибка записи регистров отмечается в логе автозапуска и в результате задачи. Отключённая в Планировщике задача остаётся отключённой при сохранении профиля.
- **Восстановление.** Если в бэкапе указан профиль автозапуска, а его содержимое отсутствует, восстановление останавливается до записи настроек. Сбой обновления списка после восстановления отмечается отдельно.
- **Драйвер и автозапуск.** DTIMOD проверяет запросы к регистрам по ресурсам выбранного устройства. Перед загрузкой программа сверяет файл драйвера, а при сбое обновления автозапуска восстанавливает прежние файлы и задачу. Если загружена старая сборка DTIMOD, перезагрузите Windows перед использованием обновлённого драйвера.

## Скачать

- [DEVICE.TWEAKER.SelfContained.exe](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/download/v0.1.0/DEVICE.TWEAKER.SelfContained.exe) включает .NET.
- [DEVICE.TWEAKER.exe](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/download/v0.1.0/DEVICE.TWEAKER.exe) требует [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0).

Нужны Windows 10/11 x64 и права администратора.

IMOD и NIC ITR зависят от возможностей контроллера или адаптера. DTIMOD может конфликтовать с античитами. Условия загрузки, поведение автозапуска и ограничение PnP/питания описаны в [руководстве по драйверу](../guide/11-driver.ru.md).

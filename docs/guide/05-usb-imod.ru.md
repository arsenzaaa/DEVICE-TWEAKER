# USB-контроллеры и IMOD

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 05 · [English](./05-usb-imod.md)

## Контроллер и interrupter

xHCI-контроллер обслуживает устройства своих USB-портов. У его interrupter есть собственные Event Ring и регистры IMOD. Несколько устройств могут использовать один interrupter, поэтому при разных значениях для мыши, клавиатуры и аудио важна карта привязок.

Интервал IMOD задаётся с шагом 250 нс: `0x0` отключает модерацию, `0xC8` соответствует 50 мкс, `0xFA0` - 1 мс. В приложении `0xC8` используется как базовое значение; у контроллера или драйвера Windows значение по умолчанию может отличаться. Подробнее: раздел 5.5.2.2 [спецификации xHCI](https://www.intel.com/content/dam/www/public/us/en/documents/technical-specifications/extensible-host-controler-interface-usb-xhci.pdf).

## Выбор режима

**XHCI** задаёт одно значение для interrupter контроллера. В режиме **Устройства** доступны отдельные поля для распознанных ролей: мыши, клавиатуры, геймпада и аудио. Программа сопоставляет роли с interrupter; если надёжной карты нет, используется общее значение контроллера. **Interrupters** открывает ручную настройку по индексам.

Перед редактированием нажмите **ПРОВЕРИТЬ**, чтобы считать состояние контроллера. Разверните подробности: там видны привязки устройств и значения регистров. После переподключения, сна или перезагрузки считайте карту заново - прежний индекс может уже относиться к другому устройству. В подсказке текущего значения указано время последнего чтения.

Все три режима показаны в [примерах USB](../SCREENSHOTS.ru.md#контроллер-usb).

## Применение и сохранение

Введите значения для выбранного режима и нажмите **ЗАДАТЬ**. Программа создаёт бэкап, записывает регистры, проверяет их чтением и сохраняет конфигурацию автозапуска. Дополнительно нажимать главную кнопку **ПРИМЕНИТЬ** для этой команды не требуется.

Задача автозапуска повторно применяет профиль при входе, пробуждении и соответствующих событиях устройств. Окно программы можно закрыть. Условия загрузки драйвера и файлы автозапуска описаны в [главе 11](./11-driver.ru.md).

AUTO предлагает `0x0` для найденной мыши, `0xC8` для клавиатуры/геймпада и `0xFA0` для USB-аудио/микрофона. Проверьте ввод, стабильность аудио и нагрузку CPU в обычной работе. Уменьшение модерации может увеличить частоту прерываний; заданный интервал не прибавляется как постоянная задержка к каждому USB-отчёту.

## Удаление и восстановление

**УДАЛИТЬ** убирает общий автозапуск USB IMOD/NIC ITR и возвращает настройки модерации сетевого драйвера, которыми управляла команда **СОХРАНИТЬ** NIC ITR. Поля USB возвращаются к `0xC8`. Если DTIMOD уже загружен, программа также может сбросить регистры IMOD; запись USB пропускается, когда в конфигурации остались только записи NIC ITR. Для завершения сброса перезагрузите Windows.

Перед **УДАЛИТЬ** дополнительный бэкап не создаётся. Чтобы вернуть конкретную сохранённую конфигурацию, выберите её через **ВОССТАНОВЛЕНИЕ**. После восстановления считайте значения и проверьте работу устройств.

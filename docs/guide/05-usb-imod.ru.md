# USB-контроллеры и IMOD

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 05 · [English](./05-usb-imod.md)

## IMOD относится к interrupter

События USB обрабатываются host-контроллером. У xHCI interrupter есть Event Ring и регистр модерации IMOD. Несколько устройств могут использовать один interrupter, поэтому разные значения для ролей не всегда означают независимую настройку каждого физического устройства.

Поле IMODI задаёт минимальный межпрерывательный интервал с шагом 250 нс. Примеры: `0x0` отключает эту модерацию, `0xC8` соответствует 50 мкс, `0xFA0` - 1 мс. Условия формирования прерывания описаны в разделе 5.5.2.2 [спецификации xHCI](https://www.intel.com/content/dam/www/public/us/en/documents/technical-specifications/extensible-host-controler-interface-usb-xhci.pdf). Это не фиксированная добавка к задержке каждого USB-отчёта.

`0xC8` - базовый интервал, используемый DEVICE TWEAKER. Не следует считать его неизменным значением каждого контроллера и каждой версии Windows.

## Режимы карточки

| Режим | Что задаётся |
| :--- | :--- |
| XHCI | Общее значение для контроллера. |
| Устройства | Значения по распознанным ролям с учётом текущей карты. |
| Interrupters | Значения по индексам interrupter. |

Карта устройств может изменяться после переподключения, сна или перезагрузки. Программа перечитывает доступные данные xHCI и показывает карту и диагностические подробности. Время последнего чтения находится в подсказке текущего значения. При неполных данных смотрите применённое общее значение и причину ограничения, а не предполагайте точную привязку по старому индексу.

**ПРОВЕРИТЬ** читает регистры. **ЗАДАТЬ** применяет значения и сохраняет профиль автозапуска. **УДАЛИТЬ** удаляет общий профиль автозапуска IMOD/NIC ITR и восстанавливает модерацию сетевого драйвера. Поля USB сбрасываются в `0xC8`; запись в регистры возможна только при уже загруженном DTIMOD и пропускается, если в конфигурации остались только записи NIC ITR. Для завершения сброса перезагрузите Windows. Отдельная автоматическая копия перед удалением не создаётся.

## Политика AUTO

Для найденных ролей AUTO предлагает мыши `0x0`, клавиатуре и геймпаду `0xC8`, USB-аудио/микрофону `0xFA0`. Перед сохранением этих значений проверьте стабильность аудио и отклик устройств ввода.

Уменьшение модерации может увеличить частоту прерываний и нагрузку CPU; увеличение меняет группирование обработки. Проверяйте ввод, аудио, потери событий и нагрузку на своём контроллере. При сравнении портов разных контроллеров сохраняйте карту устройств для каждого прогона.

## Автозапуск и восстановление

Регистры могут быть переинициализированы при перезагрузке, сне или сбросе устройства. Сохранённые значения применяет PowerShell-задача; EXE не обязан оставаться открытым. Механизм и ограничения описаны в [главе 11](./11-driver.ru.md).

Readback подтверждает считанное значение регистра. Он не измеряет задержку ввода и не заменяет проверку сна, пробуждения и переподключения на настоящем оборудовании.

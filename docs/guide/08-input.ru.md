# Ввод: Polling Rate, Raw Input и Mouse Throttle

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 08 · [English](./08-input.md)

## USB polling и Raw Input

Частота USB-обмена, частота доставленных событий Raw Input и время обработки ввода игрой - разные величины. Драйвер, очередь сообщений и приложение влияют на то, когда полученные данные будут использованы. Общий API описан в [Raw Input overview](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input).

DEVICE TWEAKER показывает доступные сведения об опросе и измеряет частоту событий мыши через Raw Input. Двигайте мышью во время замера. Счётчик отражает доставку событий в приложение. Движение мыши даёт поток отсчётов; события нажатия и отпускания клавиш слишком редки для надёжной оценки polling rate клавиатуры.

## Как приложение читает ввод

Windows предоставляет чтение отдельных сообщений и [GetRawInputBuffer](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getrawinputbuffer) для накопленных данных. Буферизацию и отдельный поток ввода реализует само приложение. Их влияние оценивается измерениями в конкретной игре или программе.

Высокая частота отчётов увеличивает объём обрабатываемых событий. Сравнивайте доступные режимы мыши в конкретной игре, учитывая стабильность времени кадра и отклик.

## Mouse Throttle

На поддерживаемых сборках Windows 11 программа позволяет задать `RawMouseThrottleDuration`:

```text
HKCU\Control Panel\Mouse
  RawMouseThrottleDuration  REG_DWORD
```

В интерфейсе задаются пользовательские интервалы 1-20 мс. Подписи 1 кГц, 125 Гц и 50 Гц соответствуют расчёту `1000 / интервал`. Это запрашиваемые значения; фактическая доставка событий зависит от Windows и получателя.

Настройка относится к фоновому Raw Input, а не к USB polling rate. Переключатель доступен на поддерживаемых сборках Windows 11; на Windows 10 он неактивен. Проверка версии учитывает появление улучшений высокочастотного ввода в Windows 11 22H2, начиная с [KB5027303](https://support.microsoft.com/en-us/servicing/os/windows-11/2023/06/june-27-2023-kb5027303-os-build-22621-1928-preview).

Выключение переключателя удаляет пользовательское значение `RawMouseThrottleDuration` и возвращает штатное поведение Windows. AUTO предлагает 20 мс для фоновых получателей. Перед сохранением настройки проверьте доставку событий в затронутых приложениях.

## Когда сохраняются изменения

Выберите интервал и нажмите **ПРИМЕНИТЬ**, чтобы сохранить его после создания резервной копии. При ошибке записи правка остаётся неприменённой.

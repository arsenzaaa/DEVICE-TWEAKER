# Топология процессора и ReservedCpuSets

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 07 · [English](./07-cpu-topology.md)

## Как читать список CPU

Карточки показывают логические CPU, физические ядра, SMT-соседей и доступные сведения о CCD/CCX и CPPC. На однородных процессорах используются подписи Core и Core/SMT. На гибридных процессорах подписи P-Core и E-Core различают типы ядер. Например, `CPU 6 (Core, R131, #4)` и `CPU 7 (Core/SMT, R131, #4)` относятся к одному физическому ядру.

Рейтинг CPPC показывает, какие ядра прошивка считает более производительными. CCD и CCX обозначают чиплеты и группы ядер. Данные о кэше помогают различать CCD на многочиплетных процессорах.

## Как AUTO использует топологию

AUTO выбирает целевой CCD и физические ядра по встроенным правилам, учитывая SMT и доступные рейтинги. Для дискретной видеокарты выбирается пара физических ядер, а распределение прерываний встроенной графики остаётся за Windows. Остальные типы устройств получают собственные назначения. Если нужные сведения о топологии определить не удалось, соответствующая автоматическая настройка не записывается.

AUTO меняет только настройки устройств и не затрагивает SMT, E-ядра и привязку игровых потоков. Назначения ядер зависят от обнаруженной топологии; сравнивайте производительность на своей нагрузке.

## ReservedCpuSets

Панель **Reserved CPU Sets** резервирует логические CPU на уровне системы. Windows может использовать их, когда это необходимо, например если маска привязки потока разрешает работу только на этих CPU. В карточке устройства те же отметки задают привязку его прерываний.

Маска резервирования хранится здесь:

```text
HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Kernel
  ReservedCpuSets  REG_BINARY
```

Выберите CPU и нажмите **ПРИМЕНИТЬ**. Чтобы отменить резервирование, снимите все отметки и примените изменения. Программа удалит значение из реестра. Перед записью создаётся резервная копия. Если запись не удалась, правки остаются неприменёнными. Панель доступна, когда удалось надёжно определить идентификаторы CPU Set (CPU Set ID).

**АВТООПТИМИЗАЦИЯ** снимает резервирование, если эта панель доступна. Чтобы сохранить свою маску, настройте устройства вручную через **ПРИМЕНИТЬ**.

Модель CPU Sets и привязка потоков описаны в *Windows Internals*, 7-е изд., ч. 1, с. 278–283, и в [документации CPU Sets API](https://learn.microsoft.com/en-us/windows/win32/procthread/cpu-sets).

## Проверка выбора

Сопоставьте отмеченные CPU с физическими ядрами и CCD/CCX по подписям списка. После перезагрузки проверьте по [трассе](./10-verification.ru.md#просмотр-трассы), на каких CPU выполняются потоки и обработчики прерываний.

# Топология процессора и ReservedCpuSets

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 07 · [English](./07-cpu-topology.md)

## Как читать список CPU

Карточки показывают логические CPU, физические ядра, SMT-соседей и доступные сведения о CCD/CCX и CPPC. Однородные CPU обозначены как Core и Core/SMT, гибридные - как P-Core и E-Core. Например, `CPU 6 (Core, R131, #4)` и `CPU 7 (Core/SMT, R131, #4)` относятся к одному физическому ядру.

CPPC-рейтинг показывает относительную оценку производительности ядер, полученную от прошивки. Подписи CCD/CCX обозначают чиплеты и группы ядер; сведения о кэше помогают различать их роли на многочиплетных процессорах.

## Как AUTO использует топологию

AUTO выбирает целевой CCD и физические ядра по правилам проекта, учитывает SMT и доступные рейтинги. Для дискретной GPU используется пара физических ядер; привязка встроенной GPU возвращается Windows. Другие роли получают свои назначения. Ненадёжное определение необходимой топологии блокирует соответствующую автоматическую запись.

AUTO меняет настройки устройств, сохраняя SMT, E-cores и привязку игровых потоков. Назначения ядер зависят от обнаруженной топологии; сравнивайте производительность на своей нагрузке.

## ReservedCpuSets

В панели **Reserved CPU Sets** выбираются CPU, которые Windows должна стараться оставлять в резерве при обычном планировании потоков. Отметка здесь означает резервирование CPU; отметка в карточке устройства задаёт его interrupt affinity. Это отдельные настройки.

Маска резервирования хранится здесь:

```text
HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Kernel
  ReservedCpuSets  REG_BINARY
```

Выберите CPU в панели и нажмите **ПРИМЕНИТЬ**. Перед записью маски программа создаёт резервную копию; для проверки эффекта перезагрузите Windows. При ошибке записи правки сохраняются для повторной попытки. Панель недоступна, если CPU Set IDs не удалось надёжно определить.

Эта системная маска не назначает выбранные CPU конкретной игре. После перезагрузки проверьте фактическое планирование потоков и ISR/DPC; исходную маску сохраните для восстановления. В [документации CPU Sets API](https://learn.microsoft.com/en-us/windows/win32/procthread/cpu-sets) описаны назначения отдельным процессам и CPU Set IDs - это другой механизм.

## Проверка выбора

Сопоставьте отмеченные CPU с физическими ядрами и CCD/CCX по подписям списка. В [главе проверки](./10-verification.ru.md) описано, как изучить планирование потоков и обработку прерываний после перезагрузки.

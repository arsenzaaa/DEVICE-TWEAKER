## Политика AUTO для GPU

Для дискретной видеокарты AUTO выбирает пару физических ядер на целевом CCD, использует SpecCPU и High, включает MSI и снимает пользовательский MSI Limit. SMT-сосед одного ядра не считается вторым физическим ядром; CPU 0 по возможности обходится. Встроенной графике AUTO возвращает выбор affinity Windows.

Распределение работы между выбранными ядрами зависит от драйвера GPU. Сравните AUTO с исходными настройками под одинаковой нагрузкой.

## Ручная настройка

В карточке GPU доступны CPU Affinity, MSI Mode/Limit, IRQ Priority и Policy. После применения политики прерываний перезагрузите Windows и считайте IRQ Mode заново.

Сначала сравните исходное поведение с предложением AUTO. При дальнейшем эксперименте меняйте один параметр и сохраняйте одинаковую игровую сцену, ограничитель FPS, режим питания и настройки графики. Сравнивайте повторные прогоны, а не лучший единичный результат.

## Что смотреть в трассе

Проверьте фактические ISR/DPC и рабочие потоки графического стека. Interrupt Affinity не задаёт affinity всех потоков GPU-драйвера; целевой CPU DPC может задаваться отдельно драйвером. См. [организацию очередей DPC](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/organization-of-dpc-queues).

Сохраняйте названия модулей и длительности вместе с версией драйвера, моделью GPU, состоянием HAGS и описанием нагрузки.

## HAGS и BIOS

Программа не управляет HAGS, потоками графического драйвера или firmware. Сравнение HAGS - отдельный эксперимент с собственными условиями измерения.

Критерий результата - стабильная работа и воспроизводимые измерения вашей системы. При ухудшении верните сохранённые настройки через **ВОССТАНОВЛЕНИЕ**.

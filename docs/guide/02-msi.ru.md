# MSI и MSI-X

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 02 · [English](./02-msi.md)

## Линия и сообщение

PCI-устройство сообщает о событии через линию прерывания или сообщение. MSI использует запись в память вместо сигнального вывода; MSI-X даёт драйверу больше возможностей управления сообщениями. Доступные режимы зависят от устройства и драйвера. Подробнее: [message-signaled interrupts](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/introduction-to-message-signaled-interrupts).

## Сохранённое значение и текущий режим

**MSI Mode** - выбранная настройка устройства. Изменение в списке сначала остаётся правкой; **ПРИМЕНИТЬ** записывает `MSISupported` в реестр. После этого перезагрузите Windows, чтобы проверить работу драйвера с новой настройкой.

**IRQ Mode** показывает текущий режим прерываний. Кнопка **СЧИТАТЬ IRQ** вверху окна обновляет сведения обо всех PCI-устройствах списка, включая скрытые фильтром карточки. При необходимости эта команда загружает DTIMOD. Фоновые чтения используют ресурсы Windows или уже загруженный драйвер.

Например, **MSI Mode: Включено** вместе с **IRQ Mode: Line** означает, что сохранённая настройка и текущий режим различаются. Если MSI только что применён, перезагрузите Windows и считайте режим заново. Если расхождение осталось, проверьте устройство и его драйвер: сама запись в реестре ещё не означает, что MSI используется.

В строке **HW** перечислены возможности устройства и доступный максимум сообщений. Рядом **IRQ** показывает сведения о выделенных ресурсах прерываний. Устройство может получить один ресурс при поддержке нескольких сообщений. Если данных хватает только для определения сообщений в целом, отображается **MSI/MSI-X**. Чтение конфигурации PCI позволяет уточнить режим.

## MSI Limit

**MSI Limit** ограничивает запрашиваемое число сообщений. **Unlimited** удаляет пользовательский лимит: число выбирают Windows и драйвер. Максимум в **HW** описывает возможности оборудования, а не рекомендуемую настройку.

Для MSI Windows принимает 1, 2, 4, 8 или 16, для MSI-X - до 2048. Подробнее: [включение MSI через реестр](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/enabling-message-signaled-interrupts-in-the-registry). Программа проверяет введённое значение по доступным сведениям об устройстве.

## Применение и восстановление

Выберите режим и лимит, нажмите **ПРИМЕНИТЬ** и перезагрузите Windows. Затем заново считайте **IRQ Mode** и проверьте привычную работу устройства под той же нагрузкой. Сохранённые исходные параметры можно вернуть через **ВОССТАНОВЛЕНИЕ**.

Если PCI явно сообщает о поддержке сообщений без линейных прерываний INTx, программа отклоняет отключение MSI и оставляет эту настройку без изменений.

AUTO включает MSI и снимает пользовательский лимит у настраиваемых категорий устройств. **СБРОС WINDOWS** сохраняет MSI Mode и Limit; для возврата этих двух параметров к прежним значениям нужен подходящий бэкап.

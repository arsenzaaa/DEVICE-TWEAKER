# MSI и MSI-X

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 02 · [English](./02-msi.md)

## Линия и сообщение

PCI-устройство сообщает о событии через линию прерывания или сообщение. MSI использует запись в память вместо сигнального вывода; MSI-X даёт драйверу больше возможностей управления сообщениями. Доступные режимы зависят от устройства и драйвера. Подробнее: [message-signaled interrupts](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/introduction-to-message-signaled-interrupts).

## Сохранённое значение и текущий режим

В поле **MSI Mode** выбирается настройка устройства. Кнопка **ПРИМЕНИТЬ** записывает `MSISupported` в его раздел реестра.

**Режим IRQ** показывает текущий режим прерываний. Кнопка **СЧИТАТЬ IRQ** вверху окна обновляет сведения обо всех PCI-устройствах списка, включая скрытые фильтром карточки. При необходимости эта команда загружает DTIMOD. Фоновое чтение использует ресурсы Windows или уже загруженный драйвер.

Например, сочетание **MSI Mode: Включено** и **Режим IRQ: Line** означает, что в реестре MSI включён, но сейчас устройство использует линейное прерывание. Если после перезагрузки показания остались такими же, проверьте устройство и его драйвер.

Строка **HW** показывает поддерживаемые режимы и максимальное число сообщений. Число рядом с **IRQ** показывает количество ресурсов прерываний по данным WMI. Устройство может получить один ресурс прерываний при поддержке нескольких сообщений. Если подтверждены прерывания по сообщениям, карточка показывает **MSI/MSI-X**, пока данные конфигурации PCI не позволят уточнить режим.

## MSI Limit

**MSI Limit** ограничивает запрашиваемое число сообщений. **Unlimited** удаляет пользовательский лимит: число выбирают Windows и драйвер. Максимум в **HW** описывает возможности оборудования, а не рекомендуемую настройку.

Windows принимает для MSI значения 1, 2, 4, 8 и 16. Для MSI-X допустимы значения до 2048. Подробнее: [включение MSI через реестр](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/enabling-message-signaled-interrupts-in-the-registry). Программа проверяет введённое значение по доступным сведениям об устройстве.

## Применение и восстановление

Выберите режим и лимит, нажмите **ПРИМЕНИТЬ** и перезагрузите Windows. Затем заново считайте **Режим IRQ** и проверьте обычную работу устройства под той же нагрузкой. Сохранённые исходные параметры можно вернуть через **ВОССТАНОВЛЕНИЕ**.

Если возможности PCI явно указывают на поддержку сообщений без линейных прерываний INTx, программа не даёт отключить MSI и оставляет эту настройку без изменений.

AUTO включает MSI и снимает пользовательский лимит у настраиваемых устройств. Для аудио через видеокарту лимит сохраняется. Wi-Fi программа пропускает. **СБРОС ПО УМОЛЧАНИЮ** сохраняет MSI Mode и Limit. Вернуть прежние значения этих полей можно из бэкапа.

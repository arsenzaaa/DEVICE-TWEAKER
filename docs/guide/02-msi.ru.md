# MSI и MSI-X

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 02 · [English](./02-msi.md)

## Линия и сообщение

Line-based interrupt использует линию прерывания; MSI передаётся записью по специальному адресу памяти. MSI-X расширяет управление сообщениями. Выбор зависит от возможностей устройства и его драйвера. См. [Introduction to message-signaled interrupts](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/introduction-to-message-signaled-interrupts).

MSI не означает автоматически меньшую задержку или отсутствие прерываний DPC. DEVICE TWEAKER позволяет задать настройку, но совместимость и результат проверяются на конкретном устройстве после перезагрузки.

## Сохранённое значение и текущий режим

| Поле | Что показывает |
| :--- | :--- |
| MSI Mode | Настройку `MSISupported` в реестре. |
| IRQ Mode | Доступные сведения о текущем режиме: Line, MSI, MSI-X либо объединённое MSI/MSI-X. |
| HW | Возможности самого PCI-устройства и доступный максимум сообщений. |
| IRQ Count | Сведения о выделенных ресурсах; это не измерение частоты прерываний. |

**СЧИТАТЬ IRQ** опрашивает все PCI-устройства в списке и при необходимости загружает DTIMOD. Программа читает ресурсы прерываний Windows и конфигурацию PCI. Фоновое чтение при запуске и обновлении использует ресурсы Windows или уже загруженный драйвер. Если определить режим не удалось, рядом указывается причина; настройка реестра отображается отдельно.

## MSI Limit

`MessageNumberLimit` задаёт верхнюю границу запрашиваемого числа сообщений. **Unlimited** удаляет это переопределение и оставляет выбор Windows и драйверу; это не обещание максимального числа векторов.

Windows документирует значения 1, 2, 4, 8 и 16 для multi-message MSI, а для MSI-X - предел до 2048. См. [Enabling MSI in the registry](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/enabling-message-signaled-interrupts-in-the-registry). Программа дополнительно учитывает известный аппаратный максимум и отклоняет несовместимый ввод.

```text
HKLM\SYSTEM\CurrentControlSet\Enum\PCI\<устройство>\<экземпляр>\Device Parameters\Interrupt Management\MessageSignaledInterruptProperties
  MSISupported        REG_DWORD
  MessageNumberLimit  REG_DWORD
```

## Порядок настройки

1. Запишите исходные MSI Mode, IRQ Mode и HW.
2. Примените выбранный режим. Перед записью программа создаёт страховочную копию.
3. Перезагрузите Windows, считайте IRQ заново и проверьте работу устройства под нагрузкой.
4. Если устройство работает хуже, верните сохранённые значения через **ВОССТАНОВЛЕНИЕ**.

AUTO включает MSI и снимает пользовательский лимит у настраиваемых им категорий устройств. **СБРОС WINDOWS** намеренно сохраняет MSI Mode и Limit; для возврата этих параметров нужна подходящая резервная копия.

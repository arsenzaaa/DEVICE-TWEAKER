# Энергосбережение устройств

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 09 · [English](./09-power.md)

## Применение настройки питания

Измените **Энергосбережение** в карточке устройства и нажмите **ПРИМЕНИТЬ**. Перед записью программа сохранит резервную копию. При отключении [USB selective suspend](https://learn.microsoft.com/en-us/windows-hardware/drivers/usbcon/usb-selective-suspend) простаивающие USB-устройства перестают переходить в этот режим энергосбережения. Это может увеличить расход заряда аккумулятора.

AUTO отключает энергосбережение у настраиваемых устройств.

## USB и проводная сеть

Для USB программа работает с контроллером и связанными корневыми хабами, доступными параметрами Device Parameters, PnPCapabilities и WMI. Общая настройка USB selective suspend в плане питания применяется отдельно от настройки устройства.

Для поддерживаемого проводного адаптера меняется разрешение Windows отключать устройство. При изменении PnPCapabilities сохраняются остальные биты параметра. Wi-Fi исключён из автоматических изменений.

## Подтверждение результата

Программа использует WMI, если устройство предоставляет нужное свойство. При ошибке записи или проверки откройте **ПОДРОБНОСТИ** в итоговом окне. Операция с работающим устройством может завершиться ошибкой после того, как параметры уже записаны в реестр.

После изменения проверьте длительную работу, простой, сон и пробуждение. Если устройство пропадает из списка или перестаёт отвечать после сна, восстановите исходные настройки.

## Восстановление

Восстановление применяет значения из выбранной копии. USB selective suspend восстанавливается через Windows Power API для питания от сети и аккумулятора (AC/DC) в схеме питания, записанной в бэкапе, затем проверяется чтением. Текущая схема Windows остаётся выбранной. Если работающее устройство не приняло восстановленную настройку, этот шаг отмечается отдельно, даже при успешном восстановлении реестра.

# Энергосбережение устройств

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 09 · [English](./09-power.md)

## Чем управляет переключатель

Переключатель **Энергосбережение** в карточке устройства (с сохранением через **ПРИМЕНИТЬ** после автоматического бэкапа) управляет разрешением Windows переводить простаивающее устройство в энергосберегающий режим. Отключение [USB selective suspend](https://learn.microsoft.com/en-us/windows-hardware/drivers/usbcon/usb-selective-suspend) не даёт USB-контроллерам и хабам засыпать при простое. Ценой чуть большего энергопотребления (и расхода батареи на ноутбуках) это помогает убрать задержки пробуждения или кратковременные отвалы периферии.

**АВТООПТИМИЗАЦИЯ** отключает энергосбережение для настраиваемых USB-контроллеров и проводных сетевых адаптеров; адаптеры Wi-Fi не затрагиваются.

## USB-контроллеры и проводная сеть

- **USB:** программа обновляет контроллер и связанные корневые хабы по доступным параметрам `Device Parameters` (`SelectiveSuspendEnabled`, `EnhancedPowerManagementEnabled`), биту `0x08` в `PnPCapabilities` ключа класса (с сохранением остальных флагов) и WMI-классу `MSPower_DeviceEnable` (`root\WMI`), если драйвер его поддерживает. Глобальный параметр USB selective suspend в схеме питания (`48e6b7a6-50f5-4782-a5d4-53bb8f07e226`) управляется отдельно от ключей конкретных устройств.
- **Проводная сеть:** меняет разрешение на отключение питания адаптера через бит `0x08` в `PnPCapabilities` (не затрагивая остальные биты) и `MSPower_DeviceEnable`, если драйвер поддерживает этот интерфейс.

## Проверка и выход из сна

Запись в реестр сохраняет настройку между перезагрузками, а WMI применяет её сразу к работающему устройству. Поскольку драйвер может отклонить живой WMI-запрос даже при успешной записи реестра, при любом предупреждении откройте **ПОДРОБНОСТИ** в итоговом окне: там указан конкретный шаг отказа.

После изменения настроек проверьте устройство под нагрузкой, после простоя и после сна/пробуждения. Если USB-устройство пропадает или перестаёт отвечать после сна, восстановите исходный бэкап.

## Восстановление из бэкапа

**ВОССТАНОВЛЕНИЕ** возвращает сохранённые параметры устройств и восстанавливает глобальный USB selective suspend через Windows Power API отдельно для сети (AC) и аккумулятора (DC) в схеме питания из бэкапа, после чего проверяет значения повторным чтением, не переключая текущую активную схему. Если работающее устройство не приняло живое обновление через WMI при успешном восстановлении реестра, этот шаг отмечается отдельно.

# Энергосбережение устройств

## Зачем выключать

Энергосбережение устройства — это переходы в пониженное состояние и обратно. Каждый выход из сна — это задержка на первом событии и лишние прерывания и DPC на переходах. Для мыши, клавиатуры, звука и сети на игровом ПК экономия не нужна.

## Где это живёт

**USB selective suspend** — параметр плана питания: разрешает USB-драйверу усыплять простаивающие порты. Он есть для питания от сети и от батареи отдельно.

```text
powercfg   SUB_USB   USB selective suspend setting   0 = выключено
```

**Разрешение отключать устройство** — галочка «Разрешить отключение этого устройства для экономии энергии» в Диспетчере устройств. За ней стоит WMI-класс `MSPower_DeviceEnable`, который сам пишет нужные значения. У сетевой карты это `PnPCapabilities`:

```text
HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e972-e325-11ce-bfc1-08002be10318}\00NN
  PnPCapabilities   REG_DWORD   24 = Windows не отключает адаптер, 16 = отключает
```

**Device Parameters** USB-контроллеров и хабов (`SelectiveSuspendEnabled`, `EnhancedPowerManagementEnabled` и похожие) читают по сути только USB-драйверы, и не каждый драйвер их поддерживает.

## Что делает DEVICE TWEAKER

- **Power Saving** в карточке USB-контроллера управляет энергосбережением контроллера и его корневых USB-хабов, включая USB selective suspend в плане питания. У проводного адаптера — разрешением Windows отключать устройство.
- После записи значения **перечитываются через WMI**. Неподдерживаемая функция, ошибка запроса или записи и несовпадение значений показываются раздельно, а не как общий «не получилось».
- USB selective suspend восстанавливается из бекапа через Windows Power API, отдельно для сети и батареи, и проверяется повторным чтением; текущий план питания не переключается.

**Вывод:** у устройств ввода, звука и сети энергосбережение выключено, результат подтверждён чтением, а не галочкой в интерфейсе.

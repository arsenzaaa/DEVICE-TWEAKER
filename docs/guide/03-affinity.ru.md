# Affinity, политики и приоритет прерываний

[Документация](../README.ru.md) / [Руководство](./README.ru.md) / 03 · [English](./03-affinity.md)

## Что меняет Interrupt Affinity

Политика устройства управляет назначением его прерываний процессорам. **SpecCPU** использует выбранную маску; она не закрепляет все DPC и потоки драйвера за теми же CPU. Microsoft рекомендует оставлять политику по умолчанию там, где она подходит. См. [Interrupt affinity](https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/interrupt-affinity-and-priority).

| В программе | Код | Выбор CPU |
| :--- | :--- | :--- |
| MachineDefault | 0 | Windows |
| AllClose | 1 | Близкие к устройству |
| Single | 2 | Один близкий |
| All | 3 | Все доступные |
| SpecCPU | 4 | Выбранная маска |
| SpreadMessages | 5 | Разные CPU для сообщений |

Назначение политик описано в [IRQ_DEVICE_POLICY](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdm/ne-wdm-_irq_device_policy). SpreadMessages распределяет имеющиеся сообщения, когда это возможно; дополнительных векторов она не создаёт.

## Маска и сохранение

```text
...\Device Parameters\
  Interrupt Management\Affinity Policy
  DevicePolicy           REG_DWORD
  AssignmentSetOverride  REG_BINARY
  DevicePriority         REG_DWORD
```

В DEVICE TWEAKER бит N маски соответствует логическому CPU N в поддерживаемой группе 0. Например, CPU 8 и 9 дают `0x300`, байты `00 03 00 00 00 00 00 00`. Программа рассчитывает маску по отмеченным CPU. Если снять выбор у обычного устройства, она возвращает MachineDefault и удаляет переопределение маски. Для сетевых устройств действуют отдельные [режимы RSS/IRQ](./06-network.ru.md).

Записанная политика и фактическое распределение обработки могут различаться. После перезагрузки сравните readback и ETW-трейс.

## IRQ Priority

Undefined, Low, Normal и High задают предпочтение для обслуживания прерываний. Windows учитывает его при назначении IRQL с учётом платформы и ресурсов устройства. Это не приоритет потока приложения и не приоритет очереди DPC. См. [IRQ_PRIORITY](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdm/ne-wdm-_irq_priority).

AUTO использует High для настраиваемых им устройств. Эффект оценивается под вашей нагрузкой.

## Когда результат отличается от ожиданий

Проверьте выбранный экземпляр устройства, политику, маску, перезагрузку и текущий режим прерываний. Затем разделите ISR, DPC и рабочие потоки в трассе: драйвер может распределять их по-разному. Один занятый CPU при маске из двух CPU сам по себе не доказывает неисправность.

Для дальнейшего разбора сохраните настройки, версии и трассу. Управление firmware находится за пределами DEVICE TWEAKER; параметры прерываний проверяются через ресурсы Windows и поведение драйвера.

Для накопителей AUTO сохраняет выбор affinity за Windows. При ручной настройке используйте восстановимый эксперимент и проверяйте загрузку, ввод-вывод и стабильность; не переносите профиль другого устройства как универсальный.

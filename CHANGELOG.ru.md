# История изменений

[DEVICE TWEAKER](./README.ru.md) / История изменений · [English](./CHANGELOG.md)

## [0.0.4](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.4) - 2026-10-31

Сравнение исходников: [v0.0.3 → v0.0.4](https://github.com/arsenzaaa/DEVICE-TWEAKER/compare/b82e8d095ac3303e0bcd8607ac291f0d3dc29bc1...v0.0.4).

### Изменено

- Автозапуск IMOD/NIC ITR перенесён в Планировщик заданий. Профиль применяется при входе в Windows, выходе из сна и подключении USB-устройства.

### Добавлено

- Программа и скрипт автозапуска используют общий код доступа к регистрам. SHA-256 runtime проверяется перед компиляцией, файлы драйвера и загрузчика - при загрузке DTIMOD.
- Добавлены IRQ Mode и кнопка чтения IRQ для всех PCI-устройств. Текущий режим прерываний и возможности PCI отображаются отдельно от настройки MSI в реестре.
- Для RSS выбирается по одному логическому процессору на физическое ядро. Доступное число очередей учитывает ограничения драйвера и устройства.
- При сохранении NIC ITR отключаются поддерживаемые настройки собственной модерации сетевого драйвера; при удалении профиля предусмотрен возврат к значениям INF.
- Добавлена диагностика HVCI, Vulnerable Driver Blocklist, Microsoft Defender и служб FACEIT/Vanguard перед работой с драйвером.

### Исправлено

- Из DTIMOD.sys удалена общая команда записи в физическую память. Новая команда проверяет диапазон записи по ресурсам выбранного устройства.
- USB Selective Suspend восстанавливается через Windows Power API отдельно для питания от сети и батареи, с последующей проверкой значений.
- Для мыши отображается измеренная частота событий, в том числе когда она ниже максимума из USB-дескриптора.
- При восстановлении автоматическая очистка больше не удаляет выбранную копию и копию для отката. Ошибки восстановления питания устройства выводятся отдельно.
- Программа больше не перезаписывает профиль автозапуска, который не удалось прочитать или разобрать.
- После попытки загрузки драйвера с неопределённым результатом программа и скрипт автозапуска блокируют загрузку через резервный механизм.
- DTIMOD.sys отклоняет неполные списки аппаратных ресурсов, в том числе с повреждёнными данными после допустимого диапазона записи.

### Интерфейс

- В подсказке текущего IMOD показано время последнего чтения. После изменения состава устройств карта помечается как устаревшая.
- Статус Dual-CCD отображается как Вкл/Выкл.
- Применение, сохранение, восстановление и сброс настроек выполняют длительные операции в фоне. Обновление списка сохраняет неприменённые изменения и положение прокрутки; при ошибке поиска устройств прежние карточки остаются на экране.
- Параметры RSS, энергосбережения и сведения о драйверах читаются в фоне. При ошибке или истечении времени ожидания сохраняется прежний список устройств; запоздавшие результаты игнорируются.
- Перестройка интерфейса сохраняет состояние карточек, фокус и положение курсора в поле ввода. После частичного применения неподтверждённые настройки остаются отмечены как неприменённые.
- Английские и русские строки перенесены в файлы ресурсов. Уточнены сообщения об ошибках чтения настроек, повреждённых профилях и недопустимом MSI Limit.

### Сборка

- Исходники перенесены в src, инструменты QA - в dev/qa. Тест-панель включается только в DeveloperQa и отсутствует в обычном EXE.
- Приложение и инструменты сборки переведены на .NET 10. Сборка без встроенного .NET требует .NET 10 Desktop Runtime x64; автономная сборка включает среду выполнения.
- Workflow выпуска по умолчанию собирает выбранный коммит без публикации. Замена 0.0.4 вынесена в отдельное действие с резервной копией и проверкой скачанных файлов.

## [0.0.3](https://github.com/arsenzaaa/DEVICE-TWEAKER/releases/tag/v0.0.3) - 2026-10-01

Сравнение исходников: [v0.0.2 → v0.0.3](https://github.com/arsenzaaa/DEVICE-TWEAKER/compare/39f016b6ab5e5edda4fbb83c115aae6cff2ee4c7...b82e8d095ac3303e0bcd8607ac291f0d3dc29bc1).

### Добавлено

- WinIO заменён драйвером DTIMOD.sys с загрузкой через KDU.
- Добавлены чтение, запись и сохранение NIC ITR для поддерживаемых сетевых адаптеров Intel и Realtek.
- Расширены настройки RSS: число очередей и чтение текущего состояния через Get-NetAdapterRss.
- Добавлены измерение частоты событий мыши через Raw Input и Mouse Throttle для поддерживаемых сборок Windows 11.
- Добавлены настройки энергосбережения USB-устройств и сетевых адаптеров.
- Определение топологии CPU и подбор ядер в AUTO учитывают CPPC и AMD CCD/CCX.
- Добавлены переключение RU/EN без перезапуска, выбор резервной копии для восстановления и отчёты о результате операций.

### Исправлено

- Исправлены коды политик AllClose и All. Для MSI Limit добавлены Unlimited и проверка диапазона по возможностям устройства.

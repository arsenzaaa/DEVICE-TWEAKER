# История изменений

[DEVICE TWEAKER](./README.ru.md) / История изменений · [English](./CHANGELOG.md)

## 0.0.1

Первый выпуск **DEVICE TWEAKER REWORK**.

### Настройка устройств

- Для каждого устройства доступны MSI Mode, MSI Limit, IRQ Priority и Interrupt Affinity. Сохранённые параметры реестра и текущий режим IRQ отображаются отдельно.
- Автооптимизация подбирает ядра для видеокарты, устройств ввода и сетевых адаптеров с учётом физических ядер, SMT-потоков, P/E-ядер, CCD и доступных оценок CPPC. Настройки можно скорректировать вручную; ReservedCpuSets настраивается отдельно.
- Доступны выбор процессоров и числа очередей RSS, управление энергосбережением устройств и Mouse Throttle, а также замер частоты событий мыши через Raw Input.

### USB IMOD и модерация прерываний сети

- xHCI IMOD настраивается для контроллера целиком, по ролям устройств или по индексам interrupter. Значения можно повторно прочитать из регистров для проверки результата.
- На поддерживаемых адаптерах Intel и Realtek доступны настройка NIC ITR и чтение текущих значений.
- Профили IMOD и NIC ITR сохраняются для применения при входе в Windows, выходе из сна и поддерживаемых событиях подключения устройств. Держать GUI открытым не требуется. Для этих аппаратных операций используется DTIMOD; действуют [требования и ограничения совместимости драйвера](./docs/guide/11-driver.ru.md).

### Интерфейс и отзывчивость

- Английский и русский интерфейс, поиск по списку устройств и фильтрация по категориям.
- REFRESH заново обнаруживает устройства и считывает их настройки, повторно используя совместимые карточки. При этом сохраняются введённые значения для совместимых устройств и положение прокрутки. Изменённые и отключённые устройства обрабатываются по результатам нового обнаружения.
- Обнаружение устройств и чтение аппаратного состояния выполняются в фоне. Расчёт частоты событий мыши переиспользует результат до изменения входных данных, а таймер анимаций останавливается, когда активных анимаций нет.

### Резервные копии, восстановление и диагностика

- Сохраняются исходные настройки и дополнительные резервные копии. Через окно восстановления можно вернуть настройки устройств и сохранённые профили IMOD/NIC ITR.
- Отчёты операций отдельно показывают выполненные шаги, пропуски, предупреждения и ошибки. Логи содержат идентификатор сборки, целевые устройства, запрошенные значения и результаты этапов для разбора частично выполненных операций.

### Сборки и разработка

- Переносимые сборки для Windows 10/11 x64 доступны со встроенным .NET и без него. Для второго варианта нужен .NET 10 Desktop Runtime x64.
- В исходники включены модели оборудования и отказов, регрессионные проверки и read-only стенд интерфейса. QA-запуски выполняются последовательно, с ограничениями памяти. Модели проверяют поведение приложения; загрузка драйвера, доступ к регистрам и поведение Windows при событиях питания/PnP требуют аппаратной проверки.

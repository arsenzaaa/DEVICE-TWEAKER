## Возможности

**Интеллектуальная авто-оптимизация**

Автоматически распределяет устройства по CPU с учетом P-Core / E-Core, SMT / HT, CPPC-рейтинга, AMD CCD / CCX и роли каждого устройства. Для дискретной GPU подбирает два разных физических ядра; для USB, сети и аудио используются свои правила распределения.

**MSI / IRQ / Interrupt Affinity**

- Настройка MSI Mode, MSI Limit, IRQ Priority, IRQ Policy и Interrupt Affinity.
- Отображение текущего режима прерываний в IRQ Mode и поддерживаемых режимов в HW.
- Резервирование выбранных CPU через ReservedCpuSets.

**USB IMOD / NIC ITR / RSS**

- Чтение и настройка IMOD у поддерживаемых xHCI-контроллеров: общее значение или отдельные значения по interrupter.
- Чтение и настройка NIC ITR у поддерживаемых сетевых адаптеров, информация по очередям и RX/TX.
- Сохранение профилей IMOD / NIC ITR для применения при следующем входе в Windows.
- Настройка базового CPU, количества очередей и режима RSS/IRQ у сетевых адаптеров NDIS.

**Определение устройств и Polling Rate**

Автоматически определяет GPU, USB, сетевые адаптеры, аудио и контроллеры накопителей. Показывает, к какому USB-контроллеру подключены мышь, клавиатура, геймпад, микрофон и аудио. Отображает Polling Rate мыши / клавиатуры и замеряет частоту событий Raw Input.

**Дополнительно**

- RawMouseThrottleDuration на совместимых сборках Windows 11.
- Энергосбережение USB-контроллеров, корневых хабов и проводных сетевых адаптеров.
- Бекапы, восстановление выбранной копии, удаление старых копий и сброс настроек.
- Подробные логи: что определено, что применено, что пропущено и почему.

## Использование

1. Скачайте нужную сборку и запустите от имени администратора.
2. Для интеллектуальной авто-оптимизации нажмите **АВТООПТИМИЗАЦИЯ**. При наличии подходящих xHCI-контроллеров программа предложит включить USB IMOD. NIC ITR настраивается вручную.
3. Для ручной настройки выберите параметры и нажмите **ПРИМЕНИТЬ**. Перед применением программа создаст бекап; интеллектуальная авто-оптимизация сохраняет исходные настройки.
4. После применения перезагрузите компьютер. Восстановить настройки из выбранного бекапа можно через **ВОССТАНОВЛЕНИЕ**.

<details>
<summary><strong>Отдельные кнопки IMOD / NIC ITR</strong></summary>

- IMOD: **ЗАДАТЬ** применяет настройки и сохраняет значения, отличающиеся от стандартных, для следующего входа в Windows.
- NIC ITR: **ЗАДАТЬ** меняет текущие значения, **СОХРАНИТЬ** сохраняет профиль для следующего входа в Windows.
- **ПРОВЕРИТЬ** считывает текущие значения IMOD / NIC ITR.
- **ОБНОВИТЬ** повторно определяет устройства. Общая кнопка **ПРИМЕНИТЬ** также применяет USB IMOD вместе с настройками устройств.

</details>

<details>
<summary><strong>Как считывается IRQ Mode</strong></summary>

MSI Mode показывает настройку из реестра, IRQ Mode показывает текущий режим прерываний.

При открытии программа использует уже загруженный DTIMOD.sys или ресурсы Windows, без загрузки драйвера. Если по ресурсам Windows нельзя отличить MSI от MSI-X, отображается MSI/MSI-X.

Общая кнопка **СЧИТАТЬ IRQ** читает режимы всех отображаемых PCI-устройств через DTIMOD.sys; при необходимости загружает драйвер. Поддерживаемые устройством режимы показаны отдельно в HW.

</details>
